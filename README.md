# Cat's House

Собственный открытый веб-проект для ведения и просмотра семейного дерева.

Проект хранит генеалогические данные, фотографии и документы в независимой инфраструктуре владельца. Он не требует установленного Gramps и не использует Gramps как рабочее хранилище данных. Открытый код Gramps может быть перенесён или адаптирован только с сохранением авторства и условий лицензии AGPL-3.0.

## Статус

В репозитории создаётся технический фундамент: русская веб-оболочка, собственный API и PostgreSQL, в которой хранятся и данные, и фото с документами. Импорт семейных данных, дерево и редактор добавляются отдельными этапами.

## Лицензия и атрибуция

Исходный код Cat's House распространяется по [GNU AGPL-3.0](LICENSE). Сведения об исходных файлах, перенесённых или адаптированных из Gramps, ведутся в [NOTICE](NOTICE). Локальная проверка не позволит добавить явно помеченный Gramps-производный файл без записи в этой таблице.

Семейные данные, фотографии, документы, резервные копии и секреты не хранятся в этом репозитории.

## Публичное семейное дерево

Публичная ветвь доступна по `GET /api/v1/tree/{person_id}`. Параметр `mode`
принимает `close` (ближайшие родственники), `ancestors`, `descendants`,
`mixed`, `path` и `all` (весь доступный публичный компонент); для `path`
обязателен второй человек в параметре `to`. Параметр `depth` ограничивает
ветвь от 1 до 5 поколений в режимах, где глубина применима.

Ответ содержит карточки людей, союзы и типизированные связи родитель–ребёнок.
Архивированная запись остаётся на публичном графе как «Сведения скрыты», чтобы
не разрывать линии родства, но её имя и личные сведения не возвращаются.

Чтобы вручную проверить режим «Вся семья», запустите приложение по инструкции
выше, откройте страницу дерева человека, нажмите «Вся семья» и убедитесь, что
граф вписался в полотно. Адрес должен содержать `mode=all`, а кнопки изменения
числа поколений должны быть отключены. Для проверки API откройте в браузере
`http://localhost:8000/api/v1/tree/ИДЕНТИФИКАТОР?mode=all` и убедитесь, что
ответ содержит доступных публичных людей этого компонента.

Кнопка «↑ Показать ещё N» над карточкой раскрывает скрытых родителей
человека, «↓ Показать ещё N» под карточкой — скрытых детей. Центр и режим не
меняются, уже показанные карточки остаются на своих местах на экране, новые
дописываются рядом и коротко подсвечиваются. Раскрытия сохраняются в адресе:
`expand=up:ИДЕНТИФИКАТОР,down:ИДЕНТИФИКАТОР`.

Сквозные тесты дерева кликают настоящей мышью в Google Chrome и работают с уже
запущенными API (`http://localhost:8000`) и веб-интерфейсом:

```bash
cd apps/web && CATS_HOUSE_E2E_URL=http://localhost:5176 npm run test:e2e
```

### Вход владельца

Ссылка «Вход для владельца» в шапке ведёт на `/login`. После входа в шапке
видно «Владелец · Выйти». После пяти неверных паролей за 15 минут вход с
этого адреса временно блокируется.

Новый пароль задаётся командой; она дважды спросит пароль (не менее 12
символов) и запишет только его хеш в `.env`. После смены перезапустите API.

```sh
apps/api/.venv/bin/python scripts/set-owner-password.py
```

Сквозная проверка входа запускается, только если пароль передан через
переменную окружения `CATS_HOUSE_E2E_OWNER_PASSWORD`.

### Исправление людей

Владелец открывает страницу человека и нажимает «Изменить»: фамилия, имя,
отчество, фамилия при рождении, пол, даты и места рождения и смерти. Даты
вводятся по частям и бывают точными, приблизительными («около»), «до»,
«после» и «между». Там же человека можно скрыть с сайта и вернуть. Скрытых
людей владелец находит поиском в шапке. Каждое сохранение пишется в журнал
правок. После первой правки пересборка событий из AT5 больше не запускается.

Части имени один раз заполняются из AT5 (пробный прогон, затем `--apply`):

```sh
apps/api/.venv/bin/python scripts/backfill-name-parts.py --at5 "/абсолютный/путь/к/Древо.at5"
```


### Добавление родственников

На странице человека владелец видит блок «Добавить родственника»: ребёнка,
родителя, супруга, брата или сестру. Родственника можно ввести как нового
человека или выбрать из архива; при вводе нового сайт показывает возможные
дубли. Для ребёнка выбирается второй родитель или «неизвестен». Каждое
добавление выполняется целиком или не выполняется совсем и пишется в журнал
правок. Резервная копия сохраняет части имени и людей, добавленных на сайте.

### Исправление связей

На странице человека у владельца есть блок «Связи»: родителя можно заменить
(на нового человека или из архива) или убрать, союз — изменить (дата и место
брака, отметка «В разводе» и дата развода) или убрать, если в нём нет детей,
ребёнка — перенести в другой союз или убрать. Связи убираются без удаления
самих людей. Сайт сам называет супруга родителя отчимом или мачехой, ребёнка
супруга — пасынком или падчерицей, а супругов после развода — бывшими. В
дереве союз в разводе рисуется пунктиром.

### Биографии, фото и документы

На странице человека владелец пишет биографию (простой текст, абзацы через
пустую строку, до 20 000 знаков) и загружает фото и документы: JPEG, PNG или
PDF до 10 МБ, можно несколько сразу. У файла есть подпись и дата; его можно
скрыть (тогда его видит только владелец), удалить или сделать портретом —
портрет стоит в шапке страницы и на карточке в дереве. Файлы и их уменьшенные
копии хранятся в PostgreSQL; скрытый файл гость не откроет и по прямой ссылке.
Резервная копия кладёт файлы рядом с JSON-архивом, восстановление возвращает
их в базу. Настройки `CATS_HOUSE_S3_*` больше не нужны.

### Публикация с Mac (временный адрес)

Сайт можно открыть в интернет прямо с этого Mac через бесплатный туннель
Cloudflare. Один раз установите программу туннеля и включите двухфакторный
вход владельца (понадобится приложение-аутентификатор на телефоне):

```sh
brew install cloudflared
apps/api/.venv/bin/python scripts/enable-owner-totp.py
```

Затем запуск:

```sh
scripts/serve-public.sh
```

Команда собирает сайт, при необходимости снимает копию базы и применяет
миграции, запускает сайт на порту 8100 и печатает адрес вида
`https://….trycloudflare.com`. Адрес меняется при каждом запуске; сайт виден,
пока команда работает, и Mac в это время не засыпает. Ctrl-C — остановить.
Поисковикам запрещено индексировать сайт; с одного адреса — не больше 120
запросов в минуту (владельца это не касается). `--without-2fa` разрешает
запуск без двухфакторного входа — только если вы понимаете риск.

## Проверка атрибуции

```sh
node scripts/check-notices.mjs путь/к/файлу
```

Команда проверяет только файлы, содержащие отдельную строку-комментарий `// Gramps-derived:` (также допускаются `#`, `/*` и `*` в начале строки). Если файл отмечен как производный от Gramps, но отсутствует в `NOTICE`, команда завершится с ошибкой.

## Первый локальный запуск

Нужны Docker Desktop, Node.js 24+ и Python 3.12+.

```sh
cp .env.example .env
# В .env задайте Argon2-хеш собственного пароля, секрет сессии и режим окружения.
# Значения replace-* намеренно не позволяют API запуститься.

cd apps/api
python3 -m venv .venv
.venv/bin/pip install -e '.[dev]'
cd ../web
npm install
cd ../..
docker compose up

Для повседневной локальной разработки удобнее нативный режим: `scripts/dev-native.sh`.
Он оставляет Docker только для PostgreSQL, а API и web запускает из
ваших виртуального окружения и `node_modules`. Перед первым запуском установите
зависимости API и web, затем создайте `.env` из `.env.example`.
```

Для генерации хеша пароля используйте `apps/api/.venv/bin/python -c "from argon2 import PasswordHasher; print(PasswordHasher().hash('ваш-пароль'))"`, а для секрета сессии — `apps/api/.venv/bin/python -c "import secrets; print(secrets.token_urlsafe(48))"`. В локальной разработке укажите `CATS_HOUSE_ENVIRONMENT=development`; перед публикацией — `production`, где cookie владельца всегда требует HTTPS.

Веб-интерфейс будет доступен по адресу `http://localhost:5173`, а API — по адресу `http://localhost:8000/api/v1/health`. Порты опубликованы только на `localhost`.

## Локальный импорт GEDCOM

Импорт доступен только после входа владельца и состоит из предпросмотра и отдельного применения. Замените `ВАШ_ПАРОЛЬ`, путь и идентификатор предпросмотра своими значениями; ни один из них не записывайте в Git.

```sh
curl -c /tmp/cats-house-cookie -X POST http://localhost:8000/api/v1/auth/login \
  -H 'content-type: application/json' \
  --data '{"password":"ВАШ_ПАРОЛЬ"}'

curl -b /tmp/cats-house-cookie -F 'file=@/абсолютный/путь/к/файлу.ged' \
  http://localhost:8000/api/v1/admin/imports/preview

curl -b /tmp/cats-house-cookie -X POST \
  http://localhost:8000/api/v1/admin/imports/ИДЕНТИФИКАТОР_ПРЕДПРОСМОТРА/apply
```

Сначала проверьте отчёт предпросмотра. Применение создаёт набор данных целиком либо не создаёт ничего при ошибке.

Если GEDCOM был экспортирован из локального файла «Древо Жизни» (`.at5`),
локальная команда может восстановить события, не попавшие в экспорт. Оба пути
должны быть абсолютными; AT5 открывается только для чтения и не загружается в
API или Git:

```sh
python scripts/import-local-gedcom.py \
  --file "/абсолютный/путь/к/1.ged" \
  --at5 "/абсолютный/путь/к/Древо 2.at5" \
  --apply
```

Без `--apply` команда создаёт только предпросмотр. Она выводит только
количества и количество проблем, без имён и содержимого семейных данных.

Для полной локальной проверки без удаления данных Docker:

```sh
scripts/verify-foundation.sh
```

Сценарий использует безопасные значения из `.env.example`, запускает необходимые контейнеры, проверяет API и останавливает только контейнеры, которые он запустил сам. Постоянные тома PostgreSQL и локального S3-эмулятора не удаляются.

## Пересборка событий из AT5

Файл «Древо Жизни» (`.at5`) — источник истины для событий: рождений, смертей и
браков, их участников и дат. Команда пересобирает все события сайта из AT5.
Люди, союзы и родственные связи не меняются, поэтому ссылки на страницы людей
сохраняются. Люди, удалённые с сайта, не возвращаются. Без `--apply` выполняется
пробный прогон с отчётом из одних чисел; с `--apply` изменения записываются
одной транзакцией. Если на сайте уже есть ручные правки, места или описания
событий, команда останавливается, чтобы их не перезаписать. Перед применением
сделайте резервную копию (раздел ниже).

```sh
python scripts/sync-at5-events.py --at5 "/абсолютный/путь/к/Древо.at5"
python scripts/sync-at5-events.py --at5 "/абсолютный/путь/к/Древо.at5" --apply
```

## Локальная резервная копия

Команда создаёт переносимый JSON-архив всей структуры, отдельный GEDCOM и каталог с копиями медиа-файлов. Каталог должен быть абсолютным.

```sh
python scripts/create-local-backup.py --output "/абсолютный/путь/к/резервным-копиям"
```

Для ежедневного запуска добавьте эту же команду в планировщик ОС (cron или launchd) с теми же переменными `CATS_HOUSE_*`, что использует API.

Восстановление выполняется в пустую базу той же командной строкой и возвращает как структуру, так и медиа-файлы:

```sh
python scripts/restore-local-backup.py --archive "/абсолютный/путь/к/cats-house-YYYYMMDDTHHMMSSZ.json"
```
