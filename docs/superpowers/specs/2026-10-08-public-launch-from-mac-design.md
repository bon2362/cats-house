# Запуск с Mac в интернет — дизайн (этап 5.1)

Дата: 8 октября 2026
Статус: утверждённый дизайн

## Контекст и решения владельца

Этап 5 дорожной карты («Переносимость, защита и запуск») разбит на подэтапы:
5.1 — сайт с Mac владельца в интернете (этот документ), 5.2 — резервные копии
по расписанию и проверка восстановления, 5.3 — полная выгрузка GEDCOM,
5.4 — переезд на Vercel + Neon.

Решения владельца:
1. Сайт открыт всем без входа, как сейчас, но закрыт от поисковиков и
   роботов.
2. Сначала — с собственного Mac через туннель, позже — Vercel + Neon.
3. Адрес — временный бесплатный туннель Cloudflare (`*.trycloudflare.com`),
   меняется при каждом запуске.
4. Двухфакторный вход владельца включается до первого запуска.

Честное ограничение: поисковики запрет индексации соблюдают; роботы-сборщики
— не всегда. Ограничение частоты запросов мешает массовому скачиванию, но не
делает его невозможным.

## Как это работает

Команда `scripts/serve-public.sh`:
1. Проверяет, что установлен `cloudflared` (иначе — подсказка
   `brew install cloudflared`) и что включён двухфакторный вход (иначе
   отказ; обойти можно только явным флагом `--without-2fa`).
2. Собирает окончательную версию сайта (`npm run build` → `apps/web/dist`).
3. Если в базе есть непримененные миграции — снимает полную копию базы
   (`pg_dump` в `~/cats-house-backups/before-migrate-<время>.sql`) и
   применяет их.
4. Запускает API на `127.0.0.1:8100` в «публичном режиме» с
   `CATS_HOUSE_ENVIRONMENT=production`; API же отдаёт собранные страницы.
5. Запускает туннель `cloudflared tunnel --url http://127.0.0.1:8100` и
   печатает адрес сайта.
6. Пока команда работает, Mac не засыпает (`caffeinate`). Ctrl-C
   останавливает API и туннель.

Обычная разработка (`scripts/dev-native.sh`, порты 5176/8000) не меняется и
может работать одновременно.

## Изменения API

Новые необязательные настройки:
- `CATS_HOUSE_WEB_DIST` — папка собранного сайта. Если задана, API отдаёт
  из неё файлы, а на любой другой адрес вне `/api/` — `index.html` (страницы
  сайта открываются по прямым ссылкам).
- `CATS_HOUSE_PUBLIC_MODE` (`true`/`false`, по умолчанию `false`) —
  включает доверие заголовку туннеля и ограничение частоты запросов.

Всегда (в любом режиме):
- Заголовки на каждом ответе: `X-Robots-Tag: noindex, nofollow, noarchive`,
  `X-Frame-Options: DENY`, `Referrer-Policy: same-origin`,
  `X-Content-Type-Options: nosniff`.
- `GET /robots.txt` → `User-agent: *` / `Disallow: /` (и тот же файл в
  `apps/web/public/` для сервера разработки).
- В `index.html` — `<meta name="robots" content="noindex, nofollow">`.

Только в публичном режиме:
- Адрес посетителя: если запрос пришёл с `127.0.0.1`/`::1` (то есть через
  туннель) и есть заголовок `CF-Connecting-IP`, адресом считается его
  значение; иначе — адрес соединения. Тот же адрес использует защита от
  подбора пароля владельца (вне публичного режима — как раньше).
- Ограничение: не больше 120 запросов к `/api/` в минуту с одного адреса
  (скользящее окно, в памяти процесса). Сверх — `429` с `Retry-After` и
  текстом «Слишком много запросов. Подождите минуту.» Запросы вошедшего
  владельца не ограничиваются. Отдача страниц и файлов сборки не считается.

## Двухфакторный вход владельца

Сервер уже проверяет одноразовый код, если задан
`CATS_HOUSE_OWNER_TOTP_SECRET`, и форма входа уже показывает поле кода.

Скрипт `scripts/enable-owner-totp.py`:
- создаёт случайный секрет (160 бит, base32);
- показывает QR-код в терминале (библиотека `qrcode`) и ту же ссылку
  `otpauth://totp/Cat's%20House:<email>?secret=…&issuer=Cat's%20House`
  текстом — для ручного ввода;
- просит ввести текущий код из приложения и записывает секрет в `.env`
  только если код верный (иначе «Код не подошёл, секрет не сохранён.»);
- `--disable` убирает секрет из `.env` после подтверждения «да».
Секрет не печатается в журналы и не передаётся в аргументах команд.
Изменение вступает в силу после перезапуска API.

## Проверки

API: заголовки на ответах API и на страницах; `robots.txt`; отдача
`index.html` для адресов страниц и файлов сборки, `/api/` не перехватывается;
ограничение 120/мин (429, `Retry-After`, разные адреса считаются отдельно,
владелец не ограничен, вне публичного режима ограничения нет); доверие
`CF-Connecting-IP` только в публичном режиме и только с локального адреса;
защита от подбора пароля по этому адресу. Секрет: создание, ссылка
`otpauth`, подтверждение кодом, запись в `.env`, отключение. Web: метка
`noindex` в `index.html`. Ручная проверка: запуск скрипта, открытие адреса
туннеля с телефона, вход владельца с кодом.
