# Интерактивное дерево — уточнение дизайна

## Цель

Сделать дерево семейным графом, с которым можно работать на реальном архиве: читать полные имена, понимать все линии, выбрать человека и перейти к любой записи семьи.

## Утверждённые требования

1. Полное имя человека всегда видно на карточке. Ширина карточки вычисляется из содержимого в разумных пределах; перенос строк допускается, обрезание многоточием — нет.
2. Фото показывается только при реально загруженном изображении. Без фото карточка отдаёт освободившееся место имени и данным.
3. Клик по карточке открывает подробную карточку рядом с выбранным человеком. Она закрывается крестиком, Escape и кликом по пустому полотну. В ней есть «Сделать центром» и «Открыть страницу».
4. Линии имеют только три понятных вида: партнёрство, родитель—ребёнок, скрытые дополнительные родственники. Концы линий не остаются без объясняющей карточки или явной кнопки раскрытия; легенда объясняет стили.
5. Перетаскивание полотна начинается с любой точки, включая карточку. Короткий клик выбирает карточку; перемещение указателя дальше порога перетаскивает холст и не открывает попап.
6. Режим «Вся семья» загружает и показывает всех доступных публичных людей одним полотном. Для большого набора включаются автоматическое вписывание, поиск и переход к выбранному человеку.
7. Раскладка сначала измеряет карточки, затем размещает семейные блоки, и только после этого строит линии. Карточки не пересекаются между собой, с полосами поколений или панелью управления.

## Границы и данные

- Данные не дополняются догадками: если связь отсутствует в архиве, интерфейс её не создаёт.
- После удаления слабой дублирующей ветки локальная база содержит 280 человек в одном компоненте связности. Режим «Вся семья» не должен создавать искусственных несвязных ветвей.
- Существующие режимы «Ближайшие», «Предки», «Потомки», «Смешанное» и «Как связаны» сохраняются.
- Доступ остаётся публичным; скрытые записи не раскрывают имя, события или медиа.

## Техническое решение

- В `tree-graph.ts` вводится измеряемая модель карточки (`width`, `height`, наличие фото) и семейные блоки. Чистая функция раскладки возвращает координаты карточек, точек союзов, трасс линий и границы сцены.
- SVG остаётся слоем линий и полос поколений. Интерактивные карточки и попап становятся HTML-слоем поверх него, чтобы поддерживать переменную ширину, фото и доступность.
- `tree-page.ts` владеет камерой (масштаб, панорамирование, вписывание, центрирование), различает click/drag по порогу 6 px и позиционирует попап относительно карточки с предотвращением выхода за экран.
- Публичный API получает параметр `mode=all`; сервер возвращает весь доступный единый компонент в устойчивом порядке. При будущем появлении нескольких компонентов интерфейс показывает их отдельно и не придумывает линию между ними.

## Приёмка

- Длинное имя полностью видно на карточке на реальном наборе и в тестовой фикстуре.
- У карточки без медиа нет пустого блока под аватар, а с медиа есть изображение.
- Клик открывает попап у карточки; перетаскивание карточки перемещает дерево и не выбирает её.
- Ни одна связь не заканчивается необъяснимой точкой.
- «Вся семья» показывает 280 человек после вписывания и позволяет через поиск сделать любого из них центром.
- Целевые тесты раскладки, страницы и API проходят; после последнего изменения проходят полный API test, web test, typecheck и build.
