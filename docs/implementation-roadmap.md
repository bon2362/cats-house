# Roadmap разработки «Cat's House»

Дата: 3 октября 2026

## Назначение

Это порядок создания собственного open-source семейного сайта. Он реализует [согласованную спецификацию](specs/family-tree-open-source-product-design.md). Каждый этап заканчивается работающим, проверяемым результатом; переход к следующему этапу требует отдельного плана и проверки.

## Технический выбор для старта

| Часть | Выбор | Причина |
| --- | --- | --- |
| Веб-интерфейс | TypeScript, Lit, Vite | Lit — технология исходного интерфейса Gramps Web; это упрощает законное переиспользование и адаптацию компонентов дерева и редактора. |
| Собственный API | Python, FastAPI | Чёткий HTTP API, удобная валидация и хорошие инструменты для импорта файлов. |
| База данных | PostgreSQL | Надёжно хранит связи, события, историю правок и транзакции. |
| Файлы | S3-совместимое хранилище; локально MinIO | Фото и документы хранятся отдельно от записей базы и одинаково работают локально и на хостинге. |
| Развёртывание | Docker Compose | Один воспроизводимый комплект для разработки, тестов и хостинга. |
| Лицензия | AGPL-3.0 | Соответствует переиспользуемому коду Gramps и желанию владельца развивать проект открыто. |

## Этапы

### Этап 1. Основание проекта

Создать монорепозиторий, русскую оболочку интерфейса, собственный API, локальное окружение PostgreSQL и MinIO, базовую авторизацию владельца и правила AGPL. Результат: приложение поднимается одной командой, показывает русскую стартовую страницу, API отвечает, данные не хранятся в Gramps.

Детальный план: `docs/superpowers/plans/2026-10-03-project-foundation.md`.

### Этап 2. Генеалогическая модель и миграция

Создать собственную схему людей, союзов, родительских связей, событий, заметок, источников и материалов. Реализовать предварительный отчёт GEDCOM-импорта, атомарный импорт и сверку с исходным деревом. Результат: тестовый GEDCOM и предоставленный GEDCOM импортируются в непубличную базу с понятным отчётом.

### Этап 3. Публичный семейный просмотр и дерево

Перенести и адаптировать компоненты дерева Gramps Web в отдельный пакет проекта. Создать поиск, карточку человека, дерево от любого человека, режимы предков/потомков/смешанный/граф отношений, адаптивный мобильный вид. Результат: семья может без входа найти родственника и исследовать дерево.

### Этап 4. Русский редактор владельца

Создать закрытый режим редактирования, построенный на адаптированных паттернах Gramps: люди, союзы, родительские связи, события, биографии, заметки, источники, фото и документы. Результат: владелец ведёт дерево только в Cat's House.

### Этап 5. Переносимость, защита и запуск

Добавить GEDCOM-экспорт, медиа-архив, полный технический архив, журнал изменений, архивирование вместо опасного удаления, двухфакторную защиту, автоматические резервные копии и тестовое восстановление. Результат: данные переносимы и восстанавливаемы; продукт готов к публичному запуску.

## Условия перед началом первого этапа

1. Создать GitHub-репозиторий `Cat's House` после первого локального коммита.
2. Подключить удалённый репозиторий как `origin`.
3. Для заимствованного кода Gramps вести файл `NOTICE` с путями, авторами и лицензией каждого перенесённого компонента.
4. Не переносить реальные семейные файлы в облачные сервисы. Локальные тесты и миграция выполняются только на контролируемом хостинге владельца.
