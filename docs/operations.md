# Эксплуатация опубликованного Cat's House

Этот документ описывает текущий рабочий контур сайта. Исторические планы в
`docs/superpowers/` могут упоминать Cloudflare и временную публикацию с Mac;
они не являются инструкцией для действующего сайта.

## Адреса и инфраструктура

| Назначение | Адрес или сервис |
| --- | --- |
| Основной сайт | `https://catshouse.online` |
| Алиас | `https://www.catshouse.online` — постоянное перенаправление на основной сайт |
| API | `https://api.catshouse.online` |
| DNS и регистрация домена | Namecheap BasicDNS |
| Веб-проект Vercel | `cats-house-web`, корень `apps/web` |
| API-проект Vercel | `cats-house-api`, корень `apps/api` |
| База данных | Neon, проект `cats-house`, регион Frankfurt |

Веб-проект передаёт запросы браузера вида `/api/v1/*` в API-проект. Поэтому
посетители и владелец всегда работают через основной адрес сайта; открывать
поддомен API вручную нужно только для диагностики.

## Обычная работа

- Изменения, отправленные в ветку `main`, автоматически создают Production
  deployment в Vercel.
- Изменение переменных окружения Vercel само по себе не перезапускает API.
  После него в карточке переменной нажмите **Redeploy** и выберите
  **Production**.
- Neon может показывать compute в состоянии `Idle`. Это нормальная экономия
  ресурсов: первый запрос запускает compute автоматически.
- После замены `CATS_HOUSE_SESSION_SECRET` все активные входы владельца
  становятся недействительными. Нужно войти заново.

## Секреты и доступы

Все production-секреты хранятся только в Vercel, проект `cats-house-api`,
и имеют тип **Secret**. Их нельзя добавлять в Git, README, скриншоты или
передавать в командной строке.

Нужные переменные:

| Переменная | Назначение |
| --- | --- |
| `CATS_HOUSE_DATABASE_URL` | Строка подключения Neon с TLS |
| `CATS_HOUSE_OWNER_EMAIL` | Идентификатор владельца в сессии |
| `CATS_HOUSE_OWNER_PASSWORD_HASH` | Хеш пароля владельца, не сам пароль |
| `CATS_HOUSE_SESSION_SECRET` | Подпись сессии; только тип Secret |
| `CATS_HOUSE_ENVIRONMENT` | Значение `production` |
| `CATS_HOUSE_DEPLOYMENT` | Значение `vercel` |
| `CATS_HOUSE_OWNER_TOTP_SECRET` | Не задано: добавляется только при включении двухфакторного входа владельца |

При сбросе пароля роли Neon сохраните его в 1Password, скопируйте новую
connection string и вручную замените `CATS_HOUSE_DATABASE_URL` в Vercel.
После сохранения обязательно сделайте Production redeploy и проверьте API.

## Быстрая проверка после изменений

Проверка не выводит семейные записи, а только их количество:

```sh
curl --fail --silent https://api.catshouse.online/api/v1/people \
  | python3 -c 'import json, sys; print(len(json.load(sys.stdin)))'
```

На момент публикации результат был `285`; после добавления или скрытия людей
это число закономерно меняется. Дополнительно откройте
`https://catshouse.online`, дождитесь загрузки каталога и убедитесь, что в
счётчике указано то же количество. Проверка доступности API:

```sh
curl --fail https://api.catshouse.online/api/v1/health
```

## Если сайт не работает

1. Откройте Vercel → `cats-house-api` → **Deployments**. Последний Production
   deployment должен иметь статус **Ready**.
2. Если главная страница открывается, но каталог пуст или не загружается,
   откройте Vercel → `cats-house-api` → **Logs**. Не копируйте в чат строки
   подключения и пароли из журнала.
3. В Neon откройте проект `cats-house` → branch `production` → **Connect**.
   Убедитесь, что compute существует; `Idle` допустим.
4. При ошибке аутентификации Neon обновите `CATS_HOUSE_DATABASE_URL` новой
   строкой из Neon и сделайте redeploy. Не создавайте новую базу и не
   запускайте миграции наугад.
5. При проблеме только с доменом сверяйте записи в Namecheap с теми, которые
   показывает Vercel → **Domains**. Vercel — источник точных значений DNS.

## Резервные копии и восстановление

Локальная PostgreSQL-база сохранена как историческая копия на момент переезда,
но не синхронизируется с Neon после правок на сайте. Не используйте её как
актуальную резервную копию production.

Автоматическая независимая копия Neon на Mac пока **не настроена**. До её
реализации не удаляйте локальные данные и не выполняйте рискованные массовые
правки без отдельной выгрузки базы. Следующий эксплуатационный этап —
ежедневный `pg_dump` Neon с хранением нескольких последних копий и регулярной
проверкой восстановления в пустую тестовую базу.

Скрипты `scripts/create-local-backup.py` и `scripts/restore-local-backup.py`
предназначены для локального окружения; они не заменяют резервную копию Neon.

## Безопасность владельца

Вход владельца сейчас требует пароль. Двухфакторный вход в приложение
поддерживается, но не включён по решению владельца. Когда он понадобится,
добавьте `CATS_HOUSE_OWNER_TOTP_SECRET` в Vercel как Secret, сделайте redeploy
и сохраните код приложения-аутентификатора в 1Password.

Отдельно включите двухфакторную защиту в самих аккаунтах Vercel, Neon и
Namecheap. Это защищает инфраструктуру, а не только форму входа на сайт.
